# Email Templates & Attachments Plugin for SquirrelMail

## Overview
Allows users to create, categorize, and insert rich canned responses and email reply templates with **automatic file attachment support**.

## Features
- **Compose & Reply Integration**: "📋 Templates" button directly inside the compose button bar.
- **Automatic Attachment Injection**: Attach brochures, PDF guides, price lists, or intake forms to any template. When the template is selected, its attachments are automatically attached to the compose message!
- **Dynamic Variable Substitution**: Automatically populates `{name}`, `{email}`, `{subject}`, `{date}`, `{my_name}`, `{my_email}`.
- **Template Management**: Create, edit, categorize, and delete templates, or upload and manage attached files from the Options page or directly from the compose modal.
