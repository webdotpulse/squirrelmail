# Signature Creator & Templates Plugin for SquirrelMail

## Overview
The **Signature Creator & Templates** plugin is an interactive visual designer that empowers users to create and customize modern, professional HTML email signatures with responsive templates, real-time live preview, custom accent color palettes, logo / photo embedding, and social media badges.

## Features
- **6 Professional Signature Templates**:
  - **Modern Clean**: Sleek vertical left brand accent bar, contact tags, and social links.
  - **Corporate Two-Column**: Executive layout with company logo / avatar on left, divider, and organized contact grid.
  - **Minimalist Chic**: Compact line divider and typography for understated elegance.
  - **Executive Classic**: Formal letterhead styling with serif typography and clean borders.
  - **Tech & Developer**: Dark console badges, GitHub, and professional links.
  - **Creative Card**: Card container with call-to-action button.
- **Dynamic Live Real-Time Preview**: Updates immediately as the user modifies any field, changes template, or picks brand colors.
- **Brand Color Customization**: Native color picker to match company or personal branding across borders, titles, links, and buttons.
- **Direct Webmail Integration**: Saves directly into SquirrelMail's HTML signature (`setHtmlSig`) and plain text fallback (`setSig`) for both default and alternate identities.
- **Clipboard Export**: Instant "Copy HTML Code" and "Copy Plain Text" buttons.
- **SPA Router Compatible**: Full integration with SquirrelMail's modern single-page interface and Options navigation.
