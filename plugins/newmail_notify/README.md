# Notify New Mail Popup Plugin for SquirrelMail

## Overview
Provides instant desktop push notifications, floating in-app animated toast cards, and audio chime alerts whenever new emails arrive in the user's mailbox.

## Features
- **HTML5 Desktop Push Notifications**: Native OS popups that appear even when the webmail browser window is minimized or hidden.
- **In-App Floating Toast Cards**: Google-style floating notification cards in the top-right corner with sender avatar, subject, and direct "Read" link.
- **Synthesized Audio Chime**: Gentle audio alert powered by HTML5 Web Audio API with zero external dependencies.
- **Configurable Polling**: Background check intervals (15s, 30s, 60s, 120s, 300s) configured under Options.
