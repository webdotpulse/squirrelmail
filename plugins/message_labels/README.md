# Message Flags & Labels Plugin (Gmail Style) for SquirrelMail

## Overview
Brings Gmail-like colored message labeling, star flags, and quick filtering to SquirrelMail.

## Features
- **Gmail-Style Multi-Labeling**: Assign multiple colored labels to each message (Work, Personal, Finance, Important, To Do, Follow-up, or custom labels).
- **Label Management**: Add custom labels with unique color pickers via the Options page.
- **Message Read Dropdown**: Instant checkbox dropdown in the message viewing toolbar to quickly assign or unassign labels.
- **Sidebar Integration**: Displays all labels with live message counts in the left navigation sidebar.
